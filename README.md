# フォト年表メーカー（phototimeline）

思い出を「日付・タイトル・メモ」のテキストだけで登録し、年ごとの年表として振り返るための軽量ツールです。写真そのものは扱いません。

## 使い方

- **登録**：日付（YYYY-MM-DD）・タイトル・メモを入力して登録します。
- **年表表示**：登録した思い出が年ごとにまとまって表示されます。新しい年が先、同じ年の中では日付順です。
- **削除**：各思い出の「削除」ボタンから消せます（確認ダイアログ付き）。

顔検出や画像のアップロードは行いません。テキストだけのシンプルな年表です。

データは SQLite に保存されます。DB のパスは環境変数 `PHOTOTIMELINE_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 写真ファイルのアップロード・表示には対応していません。あくまでテキストの年表です。
- 編集機能はありません（直したい場合は削除して登録し直してください）。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
